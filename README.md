# codex-jailbreak-lab
Red-team experiments and jailbreak evaluation for OpenAI Codex models.

The lab studies repository-level `AGENTS.md` jailbreak attempts and refusal
rates in Codex GPT-6.1 Sol and GPT-5.6 Sol.

Start with [Baseline 001](experiments/001-agents-boundary/README.md), a paired
experiment using a fictional output boundary and synthetic markers. The
repository contains the protocol and evaluator. Model measurements are pending.
